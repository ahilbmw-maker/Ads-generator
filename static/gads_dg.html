📘 Kako uvozim v Google Ads Editor
  1. 📁 Shrani v mapo zapiše Maaarket.xx\ads_….csv in mapo slike (samo ta paket).
  2. Editor → Account → Import → From file → izberi ads_….csv.
  3. V pregledu morajo biti samo Added, nobenega Updated.
  4. Slike: Image assets → Import from files → vse iz mape slike, nato jih pri vsakem oglasu izberi iz knjižnice (išči po SKU) + logo.
  5. Klikni Post — šele takrat gre v Google Ads.
  6. Ko v Editorju dodaš oglase ročno, naloži izvoz znova (preverba dvojnikov).
